Employee Management System | Java OOP

📌 Project Overview

The Employee Management System is a menu-driven Java application designed to manage employee records efficiently. It demonstrates core Object-Oriented Programming (OOP) concepts and provides essential operations for managing employee information.

This project was developed to strengthen Java programming skills and demonstrate practical implementation of OOP principles.

🚀 Features

- Add Employee: Register new employees with unique IDs.
- View Employees: Display all employee records.
- Search Employee: Find an employee using their ID.
- Update Employee: Modify employee details, including name, department, and salary.
- Delete Employee: Remove employee records from the system.
- Input Validation: Handle invalid inputs and prevent duplicate employee IDs.
- Menu-Driven Interface: Navigate through employee management operations using a simple console menu.

🛠️ Technologies Used

- Programming Language: Java
- Core Concepts: Object-Oriented Programming (OOP)
- Data Structure: ArrayList
- Input Handling: Scanner
- Environment: Java-compatible compiler or IDE

🧠 OOP Concepts Demonstrated

1. Encapsulation

Employee data is protected using private fields and controlled methods.

2. Classes and Objects

The "Employee" class represents employee information, while objects store individual employee records.

3. Constructors

Constructors initialize employee objects with their respective details.

4. Methods

Separate methods handle adding, viewing, searching, updating, and deleting employee records.

5. ArrayList

An "ArrayList" dynamically stores and manages employee objects.

▶️ How to Run

Prerequisites

Install Java Development Kit (JDK) or use an online Java compiler.

Steps

1. Clone or download this repository.
2. Open the project in a Java-compatible IDE or compiler.
3. Ensure the source file is named "Main.java".
4. Compile the program:

javac Main.java

5. Run the application:

java Main

6. Select an option from the menu to manage employee records.

💻 Available Operations

Option| Operation
1| Add Employee
2| View All Employees
3| Search Employee
4| Update Employee
5| Delete Employee
6| Exit

⚠️ Limitations

- Employee records are stored in memory using an "ArrayList".
- Data is not permanently saved and will be lost when the program terminates.
- The application uses a console-based interface.
